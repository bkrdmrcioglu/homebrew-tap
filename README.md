# bkrdmrcioglu/homebrew-tap

Homebrew tap for my apps.

```bash
brew install --cask bkrdmrcioglu/tap/kite
brew install --cask bkrdmrcioglu/tap/panevo
```

| Cask | Description |
|---|---|
| [kite](https://github.com/bkrdmrcioglu/Kite) | DPI bypass that runs entirely on your Mac, no VPN server |
| [panevo](https://github.com/bkrdmrcioglu/panevo) | Native window manager with snapping, hotkeys, and layout profiles |
